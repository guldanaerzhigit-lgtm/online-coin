# Royal Coins — Demo Slot

Адаптивный статический HTML5-макет, вдохновлённый визуальным стилем слотов с золотой рамкой, фиолетовым фоном, барабанами и джекпот-плашками. Это самостоятельная демо-реализация, не официальный продукт и не точная копия оригинальных игровых ресурсов.

## Возможности
- мобильная и настольная адаптация;
- 3×3 барабана и пять демонстрационных линий;
- игровой баланс и изменение ставки;
- автоигра, турбо-режим и информационное окно;
- бонусные символы и простая демонстрационная таблица выплат;
- без сервера, сборки, аккаунта или API-ключей;
- без реальных денег, депозитов или денежных выплат.

## Запуск локально
Откройте `index.html` в браузере. Для тестирования PWA/манифеста можно запустить любой локальный статический сервер.

## Публикация на Cloudflare Pages
1. Создайте репозиторий GitHub и загрузите в корень все файлы проекта.
2. В Cloudflare Dashboard откройте Workers & Pages → Create → Pages → Connect to Git.
3. Выберите репозиторий.
4. Framework preset: `None`; Build command оставьте пустым; Build output directory укажите `/` или `.`.
5. Нажмите Deploy.

## Публикация на GitHub Pages
1. Загрузите файлы проекта в корень репозитория.
2. Откройте Settings → Pages.
3. В разделе Build and deployment выберите `Deploy from a branch`, ветку `main` и папку `/(root)`.
4. Сохраните и дождитесь публикации.

> Все значения и выплаты условные, только для демонстрации интерфейса. Результаты случайны и не отражают механику оригинальной игры.
